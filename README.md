- 仓库拿货 → 对应货架补货 → 门口开店。普通日四位顾客自动到店，最多三位在店。可先给牛奶和面包各补两箱，避免首日缺货。

# PUPPY MART｜P1 教学与经营成长

默认入口已加入交互教程、员工须知、手机控制和基础经营成长。旧 P0 / v3 说明在本文后半部分保留作为历史记录。开发启动与构建命令不变。

- 首次进入按箭头实际移动→柜台笔记→取牛奶箱→补货→开店→扫描收款→打烊。教学顾客只买牛奶：售价 8，收 20，找回 12。
- 员工须知有四页教学占位说明，可随时打开；可跳过或独立重新学习。复习界面可返回正式经营，不覆盖正式存档。
- 完成首日并开始下一天后自由经营：仓库可采购，已解锁且有库存的商品才生成购物清单；一位离店后按「接待下一位」，不必每单都打烊。
- Lv.2 解锁冰柜饭团，Lv.3 解锁小花盆。目标和升级自动结算，目标不做也能继续营业。下一等级的经验与解锁会显示在界面和结算中。
- 摇杆 120px、互动键 78px、重要按钮至少 44px；支持双指移动＋互动。WASD / 方向键与 E 保留。音效可以关闭。
- 经营现场与账本自动保存本机，教程单独保存，名字沿用原键；刷新可继续取箱、收银或结算。不是云同步，请勿在多个标签同时经营。

账本明确区分销售、采购、已售成本、利润、目标奖励和可用资金。初始资金 60，初始库存为试营资产；首笔教学销售利润为 4，任务奖励另记。采购但未售的商品保留为库存，不重复扣利润。旧局没有成本记录时保留收入并显示利润暂不计算。

完整实现、修改文件、存档兼容规则和边界见 [P1 交付说明](docs/P1.md)，验证结果见 [TESTING.md](TESTING.md)。没有接入真实广告、支付、在线 AI 或编写正式文学剧情。

# PUPPY MART｜小狗便利店

当前默认入口为 **v3.0 可走动便利店垂直切片**。沿用 TypeScript + Phaser 3 + Vite、温暖复古像素方向和原角色设定。旧 P0 没有删除，访问 `?mode=classic` 可继续体验。

## v3 试玩

```sh
npm ci --cache /tmp/puppy-npm-cache
npm run dev
```

浏览器打开终端地址，给吉娃娃店长命名后进入。手机使用左下摇杆、右下互动；电脑用 WASD / 方向键走动，E 互动。摄像机跟随角色，货架、墙壁和收银台有碰撞。

1. 先到左上仓库前的圆圈，互动，取牛奶箱，返回店铺。
2. 走到中间左侧牛奶架前的圆圈，互动补货。
3. 返回仓库取面包箱，再去右侧面包架前补货。每箱 3 件，货架各容量 6，仓库各 6 件，缺货不能凭空拿取。
4. 点击「开店」（也可以先开店再补货）。一位顾客自行购物；空架时会等待，拿齐后前往收银台下侧。
5. 店长走到收银台**上侧**圆圈，互动进入收银。点两次「扫描下一件」→ 确认总价 14 → 收现金 20 → 找零 +5、+1 → 完成交易。
6. 顾客离店后可点击打烊。开店后营业时间为 5 分钟，暂停、后台及操作界面不扣时。本切片只接待一名顾客，优先测试移动和补货收银手感。

冰柜和宿舍入口是场景预留。正式《员工须知》待作者填写，现教程仅操作占位。不包含升级、多顾客经营、电子支付或新的经营存档。旧名字记录与作者源文件保留。详细审计见 [架构说明](docs/ARCHITECTURE-v3.md)。

# 经典 P0 说明

原创竖屏便利店经营游戏，当前为 **P0 基础可玩原型**。TypeScript + Phaser 3 + Vite，无后端、无在线 AI、无广告，无正式文学内容。画面由代码绘制，未使用第三方商业美术。

## 开发运行

需要 Node.js 22.12+（本次使用 24.19.0）。

```sh
npm ci --cache /tmp/puppy-npm-cache
npm run dev
```

浏览器访问终端显示的本机地址。使用已有 checkout，无需创建 worktree。

## 操作

点击开始营业，查看订单，再点击四个商品按钮配货（也支持重复商品）。购物篮最多三件；「撤销」移除最后一件，「清空」重配，配齐后「结账」。订单不考虑选择顺序，但数量必须完全一致。

每局 120 秒。前两单一件商品，第 3–6 单两件，之后三件。单价来自 `src/data/products.json`。正确结账获得商品总价，连击额外奖励为 `min(连击数−1, 5) × 2` 金币；错误结账扣 3 秒并断连，保留篮子方便修改。空篮不扣时。时间归零即打烊，显示本日金币、订单数、最高连击和失误数；再开店开始独立的新一局。

暂停会停止计时，页面进入后台自动暂停，返回后需手动继续。当前金币仅为本日分数，不持久保存；刷新即重新开始。未包含 P1 商品解锁、升级、装饰、存档，P2 剧情和作者工作台，P3 广告及 TapTap 接入。

## 手机试玩

**同一 Wi-Fi 最省事，无需部署：** 电脑运行 `npm run dev`，用手机访问 `http://电脑局域网IP:5173`。允许本机防火墙的 5173 端口。手机与云开发机器通常不在同一网络，因此云端 localhost 不能直接给手机访问。

**需要异地手机链接时，推荐免费 Netlify Drop：** 本地运行 `npm ci`、`npm run build`，登录 Netlify，把 `dist` 文件夹拖到其手动部署入口，即可获得 HTTPS 试玩地址。不需服务器、不需广告账户；免费额度和规则以服务商当前说明为准。这会把游戏部署到可被持链接者访问的网站，应在你明确决定公开托管后再做。本次未创建站点、未公开部署、未生成公网地址。

也可后续配置 GitHub Pages，但需要额外工作流和仓库路径 base 配置；P0 暂未启用自动部署。

## 目录

- `src/model.ts`：独立营业规则，可直接单元测试
- `src/data/products.json`：四种开放商品配置
- `src/scene.ts`：Phaser 原创临时店铺、吉娃娃、顾客和动画
- `src/main.ts`：移动交互、计时与结算
- `tests/`：逻辑与浏览器测试
