# P2-00｜实现与验收记录

## 实际范围

宿舍仍是结算上的**文字场景原型**，不是可走动宿舍地图。本批不做仓鼠、正式手册/收藏柜、独立高矮架、黑猫或广告。未合并 main，未操作部署。

- 结算 →「回宿舍休息」→ 可自由阅读日记 →「关灯睡觉 · 迎接明天」→ 次日。
- 宿舍随时「返回结算」；刷新恢复同晚结算，营业、资金、库存、熟客记忆保留。无需读完才睡觉。
- 日记仅正文滚动，头部返回与底部睡觉按钮常显，触控不小于 44px。320px 的滚动后首次按钮触摸通过 primary pointer release 处理；过滤兼容 click，拖动超过12px/取消不激活，键盘/普通鼠标仍走原 click。
- 原 PR 的固定“一客”与“所有人都买到了”等推断移除。首日正文来自作者在本会话确认的定稿，完整原句保存在独立 JSON：只在实际 served=1 时显示“一客”；本基线没有整理动作记录，故不显示整理句，但原句仍在数据中，未删除/改写。后续日期只有明确的「待作者填写」及独立的真实交易数提示，不代写文学。
- 先生成候选次日、成功写入原存档，再切换 UI/完成教程；保存失败仍在原夜，可重试。重复睡觉不会多跨一天。旧“完成教程”入口保留，中央礼花只在完成时播放一次。
- 无存档 schema/键迁移，不重构 world.ts / persistence.ts。未知扩展字段继续保留。日记历史收藏、贴纸、原位恢复宿舍不属于本文字原型切片，留待独立需求；本批不声称已实现。
