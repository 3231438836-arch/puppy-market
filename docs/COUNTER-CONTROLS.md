# 手册落位与独立营业按钮

手册原来仍使用旧柜台附近的硬编码坐标，在柜台移动后看起来悬在地面。本次按收银台实际坐标计算书本位置和绘制层级，放在台面左端；阅读点同步改为柜台左下侧，教程目标使用同一个 NOTEBOOK_SPOT。没有移动碰撞家具或迁移经营数据。

顶部增加独立「开店／打烊」按钮，可以在店内任意位置使用。开店仍遵守首次教程补货步骤；正常打烊仍要求所有计划顾客到店并离开，没有未完成交易。条件未满足时按钮灰色，旁边客流统计显示当前人数；打烊保留确认页。确认操作不再要求站在门口。门口 E 键操作保留兼容。

修改：`src/simulation/{scene.ts,world.ts,app.ts,tutorial.ts,immersive.css}`、集中教学文本 `src/data/tutorial.json`、教程测试；新增 `tests/browser/business-controls.spec.ts`。作者文学内容及存档键不变。

新增验证包括柜台旁阅读、原地开店、未完成客流时禁止打烊、远离门口确认打烊、320px 与横屏按钮可达，以及未知扩展字段保留。

竖屏按钮位于顶部客流行，横屏独立放在右上角，状态栏保持单行，避免新增按钮抬高面板遮挡排队顾客。触控高度至少 44px。更新了第一天手册文字与目标提示，开关店不再要求回入口。

验证：生产构建通过；43 项单元测试、18 项浏览器全套回归通过；最后横屏样式调整后另外复查营业控件与双方向布局。真机 Safari 未执行，自动化使用 Chromium 触摸模拟。源码、经营数据和作者草稿均不清空。
