基线：`759ff7c`，继续使用`feature/customer-001`开发分支。未部署正式站点，未改原有正式文学内容或人物设定。

## 审计与复用

- `world.ts`已有自动客流、队列、收银与仓鼠高货架事件。本轮复用，不重做地图/行为。
- 已有`customer001_shelf_adjusted`永久标记，`scene.ts`根据它将面包货位下移，仓鼠行为根据它跳过够不到事件。这是本轮接入的实际环境改造。
- `business.ts`已区分资金、销售、进货和成本；本轮下移的是现有货位，沿用免费调整，不新增费用或金币/经验/好感奖励。
- `persistence.ts`继续使用原有版本1经营存档和相同键名，新增可缺省字段，不另建角色数据库。
- 原《员工须知》与教程保留，新待办本是独立面板，复用现有模态、关闭、横竖屏与输入恢复机制。

## 本轮完成

### 手写待办本

固定入口位于收银台右侧，书本绘制在原柜台表面（终端与贴纸之间），互动点为`TODO_SPOT = center(12,16)`。走近后出现“查看待办”，手机点击主互动按钮/PC按E打开。

也可以从顶部“任务”→“小狗的待办事项”查看进度。这个快捷入口不会远程完成改造。

视觉采用旧纸张、墨色、手写标题/批注、绘制感勾选框；正文使用16px系统中文字体，手写字体不可用时回退。关闭及翻页按钮至少44px，支持待处理、完成历史、以后再记与逐页浏览。完成事项打勾并划去标题，正文仍可阅读。减少动态效果设置同时作用于翻页动画。

### 第一项：降低面包货位

- 仓鼠在高货架前求助时自动发现事项，记录来源“场景求助”，不会自动完成。
- 确认帮忙取下一件商品后，记录临时帮助的记入日期；长期事项仍为待处理，不安装设施、不增加奖励。
- 玩家也可主动到有货的面包货架，打开补货面板→“观察货位”，记录来源“现场观察”。观察空货架或远处调用不会生成事项。
- 只有在面包货架旁实际执行“调整摆放位置”，或打开待办本执行“降低摆放高度（免费）”，才会完成事项。
- 调整保留原有库存、商品容量、售价、资金和账本；实际商品显示位置下移，仓鼠下一次可以自行取货。
- 完成记录随存档、刷新和次日保留；重复点击/加载不重装、不重奖、不改写完成日期。
- 提前改造不会把仓鼠标记为已经见过店长，不生成好感或正式剧情。

### 其余两项

`src/data/improvements.json`中保留收银台脚凳、观察其他商品高度两项扩展数据，`enabled:false`。待办本“以后再记”可翻看简短条目，明确尚未启用，不计入待处理、完成记录，不可购买或安装。

本轮没有脚凳资产、设施价格、购买支出、碰撞或顾客使用行为。价格为null，未随意设置门槛；启用前还需要配置位置、真实操作与经济平衡。也没有新增观察型顾客剧情。

## 数据与存档

- `src/data/improvements.json`：书名、提示、来源文案、事项说明、完成条件、启用状态及设施引用。
- `src/simulation/improvements.ts`：发现、临时帮助、真实安装与校验。
- `src/simulation/todo-ui.ts` / `todo.css`：纸本面板与阅读样式。
- 经营存档新增`improvements = {version:1, entries, facilities}`。
- `entries[taskId]`记录status、source、discoveredDay、completedDay、temporaryHelpDay。
- `facilities[facilityId].installedDay`记录真实永久变化。目前只有`lowered-bread-slot`启用，继续与原NPC货位标记互相兼容。
- 无新字段的旧档使用安全默认值；旧版“已经帮助”迁移为待处理，旧版“已经下移货位”迁移为完成。旧记录没有确切日期时使用导入当天的记录日期；界面不将临时帮助记入日宣称为实际发生日，完成项使用“记为完成”表述，不伪造过往的具体发生时间。
- 有设施记录但缺失旧NPC标记时，恢复实际显示/行为标记；保存的完成事项不能仅靠文字状态而没有设施记录。
- 未识别的未来事项/设施记录保留。无效格式沿用现有只读保护，不覆盖原始存档。

## 预览方式

下载开发分支后，在自己的电脑上运行：

```bash
npm install
npm run dev -- --port 5191
```

- 电脑打开`http://localhost:5191/?npc-preview=001`。
- 手机与电脑同一Wi-Fi，使用`http://电脑局域网IP:5191/?npc-preview=001`，不要在手机上使用电脑/云环境的localhost。
- 独立预览沿用`puppy-mart.npc001-preview.v1`，不会写正常经营存档。旧预览若已经调过货位，可以直接在完成历史看到迁移记录。
- 测试发现/帮助路径：开店→面包货架「！」→帮助→跳过/读完草稿对话→柜台右侧待办本，确认仍待处理→走回货架调整→打开完成历史→刷新验证。
- 测试主动观察路径：新预览开店前到有货的面包货架→补货面板→观察货位→免费降低摆放高度。之后仓鼠自行取货。
- 如需重试首次事件，只清除独立预览键，不删除正常经营存档。本轮未提供新的公网试玩入口，没有自动发布GitHub Pages。
