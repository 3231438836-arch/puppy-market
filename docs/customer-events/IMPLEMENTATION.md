# 场景求助事件与普通顾客外观 · 增量实装

基线：`feature/customer-001` 的 `bac85fc`。未改地图、货架容量、商品成本、自动客流计划或正式文学文件；未部署正式站点。

## 审计结果与复用

- `world.ts` 已实现持久化到店计划、最多3名店内顾客、避让寻路、真实排队、一键结账、正常打烊判断。本轮继续使用这一套行为。
- `scene.ts` 原来普通顾客全用同一兔子纹理，特殊熟客仅染色。新增普通顾客纹理选择，特殊角色仍使用原有固定纹理。
- 仓鼠已有高架求助、20秒等候、帮助记录与下移货位。把头顶提示替换为货架事件标记，旧标记安全迁移。
- `app.ts` 已有可关闭弹窗、键盘 E、浮动摇杆和对话逐字显示。本轮复用，不额外建立输入管理器。
- `persistence.ts` 继续使用原有版本1与相同存档键，新增字段可缺省，不清空旧存档。不建立普通顾客关系档案。

## 通用场景事件

配置：`src/data/events/environment-events.json`。

数据包括 eventId、npcId、targetObjectId、anchorPosition、triggerConditions、interactionLabel、interactionRange、repeatPolicy、saveKey、actionId、dialogueTrigger、priority。

`src/simulation/environment-events.ts` 提供独立状态机：未触发、可交互、进行中、已完成、暂时失效。可复用于其他场景事件；本轮只注册仓鼠事件，没有添加其他NPC剧情。场景条件和动作通过 `world.ts` 适配现有 Visitor/货架数据，后续新增不同求助行为时应添加相应条件/动作适配，不复制UI或状态机。

- 像素「！」锚定面包高层货位右侧，不跟随仓鼠，不覆盖商品或库存数字。
- 最多显示2个可用标记；近距离锚点去重，先按优先级、再按玩家距离排序。当前仅一个真实事件，多事件规则由单元测试验证。
- 进入货架操作点56世界像素范围出现“帮忙拿商品”，PC用E，手机用原有主互动按钮。
- 确认帮助后同步把实际商品从货架放进购物篮，更新库存与排队状态，再标记事件完成。重复点击不能多扣库存。
- 有合格对话时自动接上原有对话界面。正常入口仍只读approved；候选台词全部保留draft，只有独立开发预览展示。台词未获批准时不为凑流程编写正式文本。
- 可随时取消操作面板；忽略事件20秒后仓鼠正常离店，事件暂时失效，其他客流继续。未完成事件以后到店可以重试；完成事件不再出现。
- 货架下移机制继续保留；下移后未来到店自行取货。
- `environmentEvents[saveKey] = {state,count}` 随经营存档保存。老存档的已帮助/已调整标记映射为完成；未触发旧存档使用空记录。中断的in-progress记录恢复为可重新判断状态，不会永久锁住。
- 事件标记本身不暂停经营。打开确认/对话面板时沿用游戏原有可关闭的模态暂停规则，不改变自动客流计划。

## 普通顾客外观

配置：`src/data/customer-appearances.json`；选择与体型：`src/simulation/customer-appearance.ts`；原创程序绘制：`src/simulation/customer-art.ts`。

本轮完成六物种各三组**临时像素素材**，总计18组，每组上下左右三帧，共216张32×40纹理：

| 物种 | 外观组合 | 主要物种轮廓 |
| --- | --- | --- |
| 兔子 | 米白 / 棕 / 斑点 | 长耳、浅内耳 |
| 猫 | 姜色 / 灰 / 三花 | 尖耳、细尾、胡须或额纹 |
| 鸭子 | 米白 / 棕 / 杂羽 | 宽喙、蹼足、圆头 |
| 刺猬 | 栗 / 灰 / 沙色 | 背刺轮廓、浅脸、突出鼻部 |
| 松鼠 | 赤 / 灰 / 深棕 | 大卷尾、短耳、浅腹 |
| 小型犬 | 黄褐 / 花斑 / 棕 | 垂耳、短口鼻 |

每组配置服装色、围巾/背包/帽子；配件与四向动作共享绘制函数。不是只有换色，物种轮廓单独绘制。保留主角普通黄褐吉娃娃及仓鼠原有画法，不为随机顾客添加姓名、正式剧情、关系或可攻略机制。

- 实际到店时只为`ordinary`选择外观，避开当日最近3个普通顾客的外观。当前每天4人，不额外跨日建立长久顾客档案。
- `Visitor.appearanceId`保存在现有flow中，刷新不重抽。旧存档或未知外观ID以访客ID确定性回退，存档原值保留。
- CUSTOMER_001和原测试熟客不参与随机池。
- 碰撞半径8–10世界像素，与32×40视觉框分离；行走按配置体型检查，队列维持至少24像素间距，适配现有一格通道。
- 普通顾客配置还保留interactionRange，并提供统一读取接口；本轮没有新增普通顾客的直接交谈入口，结账继续使用收银台操作点范围。
- 纹理只在场景创建时生成，正常更新只切换纹理，不逐帧重绘顾客。仍保持最多3位店内顾客。
- 外观仍属于可玩原型素材，需作者审美验收，不代表正式美术定稿；未制作肖像、新故事或额外特殊NPC。

## 本地预览与隔离测试

```bash
npm install
npm run dev -- --port 5191
```

- 运行项目的电脑：`http://localhost:5191/?npc-preview=001`。独立仓鼠测试存档，点击开店，走向面包货架，在「！」附近帮忙，再调整摆放位置。刷新后状态保留。
- 外观校对页（仅Vite开发服务）：`http://localhost:5191/previews/customers.html`，支持正面/背面/左右侧切换。
- 正常入口：`http://localhost:5191/`，普通顾客会自动选外观；首次普通经营仍先走教程。
- 手机需与运行Vite的电脑同网，使用该电脑的局域网IP替换localhost。云环境localhost无法从手机直接访问；本轮未创建公网预览站，未改正式GitHub Pages。
- 不要删除正常经营存档。需要重试仓鼠首次事件时，仅清除`puppy-mart.npc001-preview.v1`，保留其他记录。
