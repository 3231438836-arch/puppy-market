# 移动端沉浸式交互 v3.3

基于原有 Phaser 地图、货物、顾客路径、经营成长、教程与作者内容继续修改。经典模式保留。没有清空或更名经营、教程、人物资料存储键；新设置只在独立的布局偏好中增加可选 sensitivity 字段，旧布局默认标准灵敏度。

## 操作

- 地图铺满实际可用视口，顶部日期、资金、已完成客流和营业剩余时间。任务 ✓、库存 ▦、笔记 ▤、设置 ⚙ 主动打开浮层。
- 左侧地图 58% 区域按下出现浮动摇杆，松开、取消、切换布局、打开面板或失焦时清零。默认直径 120 CSS px，6 px 死区；支持 110/120/130 px 与三档灵敏度。近边缘时限制摇杆视觉中心，保留原触点作为拖动基准，防止初次按下跳动。
- 靠近仓库“拿货”，成功取箱自动回地图；靠近对应货架“补货”，浮层确认。靠近柜台笔记“阅读”，顾客排队到位后柜台“收银”。入口处开店，顾客离店后入口打烊。任务中可接待下一位顾客。
- 距离与朝向共同选目标，4 px 离开容差与 6 分切换阈值抑制闪烁。离开范围自动隐藏按钮。键盘 WASD/方向键、E、Escape 仍可使用。
- 当前教学使用短提示与地图高亮；完整教学说明加入《员工须知》后八页。保留跳过与设置中的重新学习，练习存档独立。教程完成出现不阻塞操作的像素礼花。
- 弹窗内的长笔记、结算账本和设置可内部滚动；关闭、翻页、次日入口保持可达。地图与核心营业操作不依赖页面或侧栏滚动。

## 兼容性边界

使用 100dvh、viewport-fit=cover、安全区域和实际视口重排，不调用方向锁定、不使用 CSS 旋转、不承诺隐藏 Safari 工具栏。镜头等比缩放并跟随角色，保持像素采样，地图碰撞和世界坐标不变。旋转不会重置手持箱、扫描、库存或资金。

本环境只能运行 Chromium 移动触摸模拟，无法连接真机 iPhone Safari；此前 WebKit 下载被环境网络代理拒绝。Safari 工具栏动态变化、刘海安全区与真实双指操作仍需作者在手机验收。Phaser 主依赖仍触发 Vite 大包提示，不影响构建。

## 手动验收

在同一浏览器打开试玩链接：竖屏进入 → 实际移动 → 阅读笔记 → 仓库拿牛奶 → 旋转横屏 → 补货 → 入口开店 → 等顾客到柜台 → 扫描 → 打开收银时旋转 → 收现金和正确找零 → 顾客离店 → 入口打烊。检查全程无页面滚动；刷新后库存、经营进度和布局灵敏度保留。设置重新学习应保留正式营业存档。

## 修改文件

- `src/simulation/app.ts`：HUD、情境动作、业务浮层、取货后恢复、短教程与礼花。
- `src/simulation/immersive.css`：铺满视口、浮动控件、安全区域与弹窗。
- `src/simulation/floating-joystick.ts`：独立指针捕获、死区、范围和释放。
- `src/simulation/interaction.ts`、`world.ts`：目标选择、朝向和入口互动点，未改变碰撞地图。
- `src/simulation/layout.ts`、`layout.css`：删除侧栏布局，新增灵敏度设置，兼容旧偏好。
- `src/simulation/tutorial.ts`、`src/data/tutorial.json`：实际入口开闭店目标、集中短教学文本，手册保留完整说明。
- `tests/interaction.test.ts` 与 `tests/browser/{simulation,tutorial,layout}.spec.ts`：单元与触摸、旋转、存档和完整营业回归。`playwright.webkit.config.ts`：可选 WebKit 检查排除 CDP 专属双指注入测试。

正式角色故事、作者工作台及文学资源没有修改。
