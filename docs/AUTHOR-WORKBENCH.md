# 作者工作台 · 基础版

入口：项目网址后加 `?mode=author`。这是静态网页中的本机编辑器，不需要账号，不会向服务器上传草稿，也不会直接写入 GitHub 仓库。

## 本批功能

- 表单修改角色公开名称、自选名字、称呼偏好、关系备注、内部身份备注和作者笔记。所有字段沿用可选作者元数据结构；内部备注不会进入玩家预览。
- 选择对话组和节点，编辑正文、肖像表情、现有选项的文字、记忆值、事件标记和目标。新增节点、事件和调整结构目前通过可展开的完整 JSON 完成。
- 校验结构、受支持素材、节点引用、选项数量、重复事件、日期/来访次数及不能结束的对话循环。无效 JSON 草稿也可保存；未校验的源配置会锁定表单，避免两份内容相互覆盖。
- 预览复用经营游戏的 Narrative 引擎，使用独立内存状态：首次到店、选择、结束、再次到店，验证历史回应。改变稿件后请重新开始预览。
- 草稿存储键 `puppy-mart.author-draft.v1`，与经营/教程/人物名字及布局键分离；刷新恢复草稿。写入前重新检查版本，不覆盖损坏或未知版本记录。
- 导入有效 JSON 后更新本机草稿，导入失败保留当前内容；导出作者 JSON 包含内部备注，因此导出提示会提醒妥善保存。文件上限 500 KB。

## 使用流程

1. 打开工作台，编辑公开名字或选择一个节点填写作者自己的文本。
2. 保存草稿。完整 JSON 修改后点击「校验并载入 JSON」。
3. 点击「从首次到店开始」，选择回应并继续到对话结束，再点「再次到店」。
4. 校验通过后导出作者 JSON，交给开发者审阅和纳入项目。导出不会自动发布，也不会替换当前游戏内容。

当前只支持既有单熟客原型及两种临时表情。修改 customerId 或扩展素材需要同步接入客流与肖像配置；工作台预览支持独立内容，不代表已接入正常营业。选择值应按含义命名并保持稳定，不要因改文字而更换既有存档使用的事件 ID 和标记。正式故事、隐藏线索与人物身份由作者决定，本轮没有扩写。

## 文件与兼容

新增 `src/author/{content.ts,app.ts,style.css}`；`src/main.ts` 增加独立入口。`src/simulation/narrative.ts` 允许传入作者配置，正常游戏仍默认同一原配置，未更名存档键或改变经营模型。原 `content/author/character-001.json` 未修改。

当前预览记忆不跨刷新保存，草稿会保存。存档是本机数据，不是云同步；避免多个工作台标签同时编辑同一草稿。工作台内容较长，可正常页面滚动，沉浸式游戏仍保持无页面滚动，两种页面独立。

尚未验证真机 iPhone Safari；自动化为 Chromium 移动触摸模拟。GitHub Pages 访问仍需区分部署分支推送与公网实际生效。
