# 音频与新增像素素材来源

- `src/simulation/sound.ts`：本轮原创程序化音高序列，使用Web Audio sine/triangle合成；不使用商业录音、第三方采样包或引用现成歌曲旋律。无需外部音频文件或音源许可证。便利店、宿舍、开场各有独立音高序列和节拍，循环并交叉淡入淡出。
- 音效：本模块原创短音序列，包括门铃、结账、补货、翻页、待办。所有音频与游戏模拟时钟分离。
- 音频在用户动作后解锁，后台挂起，单独音乐/音效音量和静音保存；iOS实际设备的音色、响度和静音开关行为仍需作者试听。
- `src/art/portraits/manager-opening.svg`：本轮原创整数网格像素图，普通黄褐短毛吉娃娃与简单围裙，无外部素材。
- `furniture-art.ts`：本轮原创整数矩形图形，UI SVG与场景绘制共用形状定义。
- 既有六物种18套顾客图及仓鼠纹理保持原有素材来源。没有引入新字体文件；手册字体使用系统中文楷体优先列表和清晰中文系统字体回退，正文可在缺少楷体时正常阅读。
