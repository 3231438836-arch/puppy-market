## 新模块

- `src/simulation/world.ts`：店铺实体、网格、移动碰撞、四邻域 BFS 寻路、库存与货箱、顾客状态机、扫描与现金找零规则。纯 TypeScript，可独立测试。
- `src/simulation/scene.ts`：Phaser 场景、地图绘制、摄像机跟随与范围限制、32×40 原创临时精灵、上下左右待机/行走帧、键盘和摇杆输入合并。
- `src/simulation/app.ts`：命名、教程占位、邻近互动、仓库与收银界面、暂停、摇杆指针捕获和日终。

模型是库存和交易的唯一来源。顾客和玩家共享可通行网格，玩家采用分步轴向碰撞防止穿透；顾客沿 BFS 得到的走道节点移动。营业与移动暂停由界面控制，打开仓库/收银操作时暂停模拟，避免操作界面消耗时间。

## 第一阶段实际范围

一间店；一个可控土黄色吉娃娃；两个货架（牛奶、面包），容量各 6；仓库初始各 6 件，每箱 3 件，拿取时从仓库扣除；一个收银台；一名顾客从入口入店，依次购买一份牛奶和面包，缺货时等待，购买后排队，结账后离店。商品不会凭空补充，库存不足无法拿箱，可原箱放回。

顾客总价沿用配置为 14，现金 20，找零 6；逐件扫描、确认总价、收现金、选零钱并交付。错误零钱不发奖，可修改；同一交易不能重复收入。离开收银台后无法远程操作，扫描进度保留。

准备阶段不计时，按开店开始 5 分钟营业；完成唯一顾客后可提前打烊。日终只报告收入与库存，不实现升级、采购成本或持久化经营。刷新/重新体验只重置本次内存模拟，不清理 localStorage。

冰柜和宿舍入口可走近查看提示，暂不提供完整内容。未添加电子支付、多顾客排队扩展、日记、正式员工须知文本、剧情、升级或广告。临时四向精灵不代表 v2.2 预览已经被作者定稿批准。

## 试玩部署

`main` 保存代码；`gh-pages` 仅保存公开构建。已有公开部署授权，更新切片预览不改仓库可见性或作者文件。命令：先 `npm run build -- --base=/puppy-market/`，再 `node scripts/publish-pages.mjs`。脚本要求已跟踪文件无未提交修改，使用临时索引生成构建提交并保留原发布分支父提交，不强推、不覆盖源码索引。网络或权限失败会直接报错。站点首次启用仍依赖仓库 Pages 设置，不能把分支推送当成已验证上线。
