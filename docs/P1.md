# P1 开发记录与验收

## 审计与保留范围

复用原移动、地图碰撞、货架、库存、寻路、收银状态机、名字、商品配置、经典模式及作者设定。没有重建项目。当前仓库尚没有完整作者工作台或正式文学引擎，P1 不假称保留不存在的功能，也不扩写文学文本。`content/author/` 与既有角色设定保持不变。

## 第一批：教程、手册与手机操作

- `src/data/tutorial.json` 集中管理 8 步教学和 4 页手册，全部标注教学占位。翻手册页不推进教程，必须实际移动、到笔记前打开、取箱、补货、等待排队、收银和打烊。
- 地图新增笔记视觉标记及当前目标圆圈/像素箭头，初始高亮店长。原地图障碍物与通道未改。教学顾客只买牛奶，避免第二种缺货打断教学。
- 支持跳过、独立复习模式（`?training=1`）、重新打开手册。复习不写入正式营业现场。
- 摇杆 120 CSS px，主互动键 78 CSS px，其余重要按钮至少 44×44；iPhone 安全区、短屏独立操作区、双指输入与主指针识别，互动按物体显示名称，过远有反馈。
- 使用原固定弹窗，退出按钮保持在顶部，手册正文 16px，不使用难读的小像素字体，翻页动效尊重减弱动画设置。

## 存档规则

全部为本机存储，不是云同步，不声称防作弊。

| Key | 用途 |
| --- | --- |
| `puppy-mart.player-profile.v1` | 旧名字记录，继续使用原实现，保留扩展字段 |
| `puppy-mart.tutorial.v1` | 正式教程步骤与完成/跳过状态 |
| `puppy-mart.shop-session.v1` | 位置、货箱、库存、顾客、扫描/找零和本局计时 |
| `puppy-mart.tutorial-replay.v1` | 独立复习教程 |
| `puppy-mart.training-session.v1` | 独立复习现场 |

每次实质操作和每秒写检查点，pagehide 再保存。教程与经营现场分开存储。读取校验失败或未知版本时保留原始记录，禁止用默认数据覆盖。没有现场检查点时，活动教程回到可执行起点；完成/跳过状态不重置。

## 第一批验收方式

新浏览器进入游戏，按箭头移动→到柜台笔记前打开→仓库拿牛奶→牛奶架补货→开店→收银。牛奶 8，现金 20，找回 12（+5、+5、+2）。顾客离店后打烊，查看结算并开始自由经营。

中途在拿箱后刷新，仍应持有同一箱，教程仍为首次补货；翻笔记不能代替补货。跳过后刷新不重弹教程；复习模式不覆盖正式营业现场。手册随时可打开。

第一批验证：构建通过，23 项单元测试、10 项浏览器测试通过。完整教程测试包含取箱后刷新恢复、首日现金交易、打烊与完成状态持久化；双指补货测试确认松开第二手指不会停止第一手指的连续移动。旧版 3 项浏览器回归继续通过。

## 第二批：经营成长

- 店铺经验与三级成长；Lv.2 解锁已有冰柜中的饭团货位，Lv.3 显示柜台小花盆，不移动原地图障碍物。
- 商品成本/解锁配置在 `src/data/business.json`；售价继续来自原商品配置，经典模式不受经营成本影响。货架容量仍为 6，每箱 3。仓库采购扣可用资金，取箱不再次扣钱，未解锁和资金不足均不扣款。
- 首次开店及后续接待只为当前已解锁、有库存的商品生成购物清单。没有可售商品时等待补货，不生成无法满足的新订单。一次只接待一位；自由营业时可按「接待下一位」继续。
- 三个每日可选目标：完成订单、补货两次、正确找零。自动领取一次；奖励金币单列，经验用于等级成长。这里「每日」指营业日，进入下一营业日才刷新，不按现实日期或断签惩罚。
- 打烊可看销售额、采购支出、已售商品成本、利润、目标奖励、可用资金、订单和库存、经验及下个解锁。没有现成满意度系统，不伪造满意度数值。
- 新游戏提供 60 初始资金和试营业初始库存（牛奶/面包各 6），初始资产不计入当天销售。固定商品成本用于已售成本核算。采购是现金换库存资产：当天采购但未售出的货物不直接扣利润。利润 = 销售额 − 已售商品成本；奖励与初始资金不计销售或经营利润。当前没有租金、损耗、批次进价等更复杂核算。
- 账本作为 `business` 扩展与营业现场存入同一个 `shop-session.v1` 记录，避免交易收入与现场分别保存造成重复发奖；教程仍单独保存。旧现场缺少账本时，保留既有销售与订单，将旧销售一次性带入资金；没有历史成本就显示「暂不计算」，不捏造旧利润，下一营业日开始完整核算。新增饭团库存字段缺失时补 0，不清空原库存。未知顶层字段继续保存，未知账本版本拒绝覆盖。
- 扫描金额、补货、交易、目标和升级有短暂反馈；原创 Web Audio 合成音效只在用户操作后使用，可关闭并在独立 `puppy-mart.settings.v1` 保存。音频失败不会阻断交易。减弱动画设置受尊重。复习继续使用单独现场与账本，不影响正式经营。

## 已知边界

本机存档不等于云同步；不保证多标签同时经营的冲突合并。自动化是 Chromium 触屏仿真，仍需 iOS Safari / Android 真机确认手感与音频。经营成长是基础版本，无真实广告或支付，无采购配送、复杂成本批次、多顾客并发或正式文学剧情。作者工作台仍需后续独立实现。
