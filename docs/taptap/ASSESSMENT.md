# TapTap 接入初步核对

参考用户提供的《TapTap Agents》正文（标注更新日期2026-10-16）。这份核对只记录接入路线，不表示已经接入或具备上传资格。

## 当前项目形态

项目是Phaser 3 + TypeScript + Vite，构建产物为`dist/`静态网页。应先核对H5游戏路线。Phaser可以使用WebGL渲染，但这不等于平台文档定义的“Tap小游戏”；不应因此改用Unity/Cocos小游戏或APK SDK流程，也不需要重做项目。

根据用户提供的文档，H5下一份对应文档是：

https://developer.taptap.cn/minigameapidoc/quick-start/mcp-guide/mcp-setup/

用户提供的说明称H5部署在平台域名下运行；具体MCP配置、包体规范、资源路径和存档域名行为仍需核对实际能力文档，不能把现有GitHub Pages链接直接等同为已经适配TapTap。

## 当前环境检查

- 已执行`taptap-cli --version`：返回command not found，说明CLI尚未安装；这不足以断言当前环境不能安装CLI。
- 当前工具清单没有TapTap MCP工具。
- 本环境请求agents.md及上述H5/MCP页面均返回HTTP 403。agents正文已由用户粘贴提供，H5/MCP详细正文尚未读取。
- 未安装TapTap SDK、CLI或Skills，未登录、创建应用、上传包体、开测试计划或提交审核。

## 如下一步选择H5自测

1. 先取得H5/MCP能力文档，核对环境可用方式。若使用CLI，安装后以实际skills/schema输出确认支持范围和H5类型取值，不猜package_type。
2. 根据实际要求列出最小适配修改，保持现有Phaser技术栈、地图和移动端操作。登录、排行榜、云存档、分析、广告均不是本轮自动接入项。
3. 在触及平台记录之前核对开发者与已有应用上下文，避免重复创建；准备具体可审阅的草稿/上传内容，再确认相应平台写操作。
4. 测试包与正式发布分开。当前自动化通过不能代替用户在真实手机上连续试玩三局的验收。
5. 上线/提审不是当前已授权工作。本轮不向用户承诺公开链接或审核时间。

## 存档注意

现有进度在浏览器本地存储。不同域名、不同浏览器或设备不会自动共享localStorage；即使保留全部旧字段，也不能承诺GitHub Pages存档自动出现在TapTap域名下。跨入口迁移方式需另行核对和设计，不能靠自动清空/替换存档解决。
