# v4.1 代码审计与分批交付

## 保留

v3.3 的铺满视口、响应式镜头、浮动摇杆、距离/朝向互动、独立布局偏好均可复用；原地图的仓库、货架、冰柜和楼梯保留。Business 的库存成本、采购现金流、利润、等级与奖励保留。经营存档键、教程键、人物名字和作者工作台不变；不改作者正式文学资源。

## 第一批：基础经营

原 ShopSimulation 只有一个 customer，nextCustomer 依赖按钮；原柜台在 (8,13)，店员在 (9,12)、顾客在 (9,14)，没有后方通道，逐件扫描状态增加触控负担。

- 柜台改为 (9,15)，宽三格；店员互动 (10,16)，顾客队列 (9,14)/(10,14)/(11,14)。柜台左右与后方有通道，门仍在 (7,18)。绘制、碰撞、寻路、互动点同步修改。
- `customer-flow.ts` 定义持久化计划、独立顾客、队列与校验。普通营业四位顾客，最多三位同时在店；随机到店间隔只生成一次并写进同一经营快照。教学一位。
- 顾客拿取时转移货架库存到篮子；结账只确认篮子、增加收入一次，不重复扣货架。paid 标记在发奖前写入，队首立即出队，下一位先移动到柜台才能再次结账。
- 寻路避开其他顾客所在格，每步检查 24 世界像素间距，阻挡时重新找路。排队宽松，不设置早期流失惩罚。营业计时到零也不丢弃未完成订单。
- HUD 待到/店内/离店按真实到店和离店计算；正常打烊必须所有计划已到、店内无人。移除手动下一位按钮。旧扫码方法与字段保留兼容，玩家界面只用一键结账。
- 旧 v1 记录缺少 flow 时转换已有顾客与已完成客流，保留篮子、收入、成本及未知扩展字段。新柜台覆盖的旧位置才安全平移，路径重新规划。未知或损坏格式仍禁止覆盖。
- 更新教学占位说明和入口/柜台高亮。完成时中央像素绽放约 1.4 秒，提示教程完成；减少动态效果可设置并独立保存，低并行设备减少粒子数。补货短描边，结账金额短反馈，不锁定操作。
