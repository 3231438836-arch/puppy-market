# 第二批交付：单熟客叙事原型

## 完成功能与结构

`src/data/narrative-test.json` 集中管理唯一测试熟客、两次非重复事件、条件、对白引用、选择和后续标记。所有文字明确标注测试占位，不构成正式角色或文学剧情。

`src/simulation/narrative.ts` 管理独立顾客档案、来访计数、最后来访日、对话标记、事件标记和关系状态。没有可见好感度数值。三个选择分别保存回应节奏，第二天同一熟客会读取它，显示不同的回访占位内容。

`src/art/portraits/test-regular-{neutral,soft}.svg` 是独立原创临时像素肖像，两种表情，与地图精灵的暖灰褐兔形轮廓一致；SVG 使用整数像素和 crispEdges，显示 144 CSS px，明显大于地图精灵。不是正式人物美术定稿。

`app.ts` 在特定熟客队首互动时打开对话；普通顾客仍然一键结账。对话不扣库存、不增加收入；结束/跳过后回到柜台，可以一键完成交易。对话打开时清零摇杆、暂停相关操作与营业计时。对话当前节点也保存，刷新后恢复，选择不会重复应用。对话结束、跳过和 Escape 均正确恢复控制。

`world.ts` 只在真实到店时增加来访次数，同一计划刷新不再计一次。`persistence.ts` 将 narrative 与 flow、库存、账本写入同一快照；缺少该字段的旧记录默认空档案，未知版本不覆盖。次日继承熟客记忆，教学练习使用独立营业记录。

## 保留与限制

只验证一位测试熟客首次到店、三个选择、再次到店记忆和继续交易。没有批量生成正式人物，没有扩展老板身份、结局、出柜或隐藏文学剧情。重复事件、更多表情和更复杂日期/条件组合留待作者内容与后续开发。

仓库中只发现作者数据 `content/author/character-001.json`，未发现独立可运行的作者工作台页面；本轮保留原数据，不擅自重建工作台。新测试配置可独立替换，不覆盖文学资源。

手机截图与验证结果见下方最终测试记录。真实 iPhone Safari、安全区和浏览器工具栏行为仍需要真机验收；自动化使用 Chromium 移动触摸模拟。

## 追加的稳定性修复

拥挤验收暴露三人排队后快速结账并刷新时，离店路线与新入店路线可能相遇。本轮将进店先导向柜台右侧通道，离店导向左侧通道，再回入口；寻路重算时先回当前格中心，逐步验证碰撞和顾客间距。新增不同到店间隔、60Hz、刷新后连续交易的模型回归，并以浏览器三人队列整日经营再次验证。对话期间模型层也拒绝结账，避免只依赖界面遮罩。

旋转时相机立即以角色为中心；旋转提示采用实际悬浮定位，对话打开时隐藏背景提示；柜台标签避免盖住店长。重要任务/升级使用少量短像素彩纸，普通交易只显示金额，打烊浮层有轻微进场效果。减少动态设置保留静态完成提示。

- 最终固定源码 `npm run test:e2e`：14/14 通过，2.6 分钟。真实键盘移动补货，四位自动顾客，先等三人进入队列再收款，中途刷新，销售 56 / 成本 28 / 利润 28，全部离店才打烊。两条回访分支均经浏览器实际次日拿货、补货、开店和自动顾客流程验证。对话初始队首使用明确的持久化测试夹具；自动客流与移动完整流程由独立用例覆盖。
